## 元数据字段设计

每个Markdown文件应包含YAML front matter:

```yaml
---
title: "经典名称（中文）"
english_title: "Classic Name (if applicable)"
author: "作者"
dynasty: "朝代（先秦/汉/唐等）"
school: "流派（daojia/rujia/mojia/fajia/bingjia/mingjia/zonghengjia/nongjia/zajia/yijia/shijia/shushujia/huanglao）"
original_text: "原文（可选）"
translation: "译文（可选，现代汉语翻译）"
annotations: "注释（可选）"
metadata:
  source: "来源网站（ctext.org / wikisource / guoxuedashi）"
  url: "原文链接"
  downloaded: "下载日期"
  format: "Markdown"
  language: "中文（古汉语）"
  license: "CC BY-SA 3.0 / Public Domain"
  quality: "high/medium/low（校对质量）"
---
```

## Chunk策略

### 分块原则
1. **按自然章节**（优先级最高）
   - 《论语》按"学而第一"、"为政第二"等篇
   - 《道德经》按第1-81章
   - 《孙子兵法》按"计篇"、"作战篇"等

2. **按自然段落**（次优先级）
   - 每段200-500字
   - 保持语义完整性

3. **重叠策略**
   - 相邻chunk重叠50-100字
   - 确保检索时不丢失边界信息

### Chunk元数据
```json
{
  "text": "章节内容",
  "metadata": {
    "school": "daojia",
    "classic": "道德经",
    "chapter": "第一章",
    "chunk_id": 0,
    "char_start": 0,
    "char_end": 500,
    "source_url": "https://ctext.org/...",
    "dynasty": "先秦"
  }
}
```

## 执行步骤

### 阶段1：数据收集（全网搜索下载）
1. 从 ctext.org 批量下载原文（使用wget/curl或手动）
2. 从 维基文库 下载对照版本
3. 统一格式为Markdown

### 阶段2：数据转换
1. 合并两个《道德经》docx → 单个完整《道德经》
2. 转换为Markdown（保持原文+译文两段式结构）
3. 添加YAML front matter

### 阶段3：预处理
1. 编写 `scripts/preprocess_for_milvus.py`
2. 自动按章节切分chunks
3. 生成 `knowledge/chunks.jsonl`

### 阶段4：Milvus导入
1. 编写 `scripts/import_to_milvus.py`
2. 使用BGE或M3E生成embeddings
3. 批量插入Milvus
4. 创建HNSW索引
