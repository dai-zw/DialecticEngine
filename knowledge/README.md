# DialecticEngine 知识库

## 概述

本知识库收录中国哲学核心经典著作，覆盖**先秦诸子**到**明清之际**的完整思想谱系，作为RAG检索的语料来源。

## RAG使用说明

### 数据结构

```yaml
---
title: "经典名称"
author: "作者"
dynasty: "朝代"
school: "流派"
period: "时代"
metadata:
  source: "来源网站"
  url: "原文链接"
  downloaded: "下载日期"
---
```

### Milvus向量化

- **分块策略**: 按篇章分块，200-500字
- **嵌入模型**: BGE、M3E等中文模型
- **元数据字段**:
  - `school`: 流派
  - `period`: 时代（先秦/汉魏/唐/宋明）
  - `classic`: 经典名
