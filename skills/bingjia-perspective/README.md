# 兵家视角 · Skill 目录说明

本目录包含兵家视角 Skill 的完整资料与运行配置。

## 目录结构

```
bingjia-perspective/
├── SKILL.md                    主技能文件（可运行的兵家战略框架）
├── metadata.json               注册表元数据（触发词、问题类型等）
├── README.md                   目录说明
├── sources/                    原始材料目录（空，已创建.gitkeep）
└── index/
│   ├── skill-card.md           Skill 速查卡
│   └── trigger-examples.md     触发示例与边界判断
└── references/research/
    ├── 01-writings.md          一手经典（孙子兵法、吴子、司马法等）
    ├── 02-conversations.md     对话风格与战略思维
    ├── 03-expression-dna.md    表达DNA：用词、节奏、战略风格
    ├── 04-external-views.md    外部批评、学派对比、边界警告
    ├── 05-decisions.md         战略案例与竞争应用
    └── 06-timeline.md          兵家思想发展时间线
```

## 使用说明

1. **SKILL.md** 是核心文件，定义了角色扮演规则、回答工作流、心智模型、启发式与表达DNA。
2. **metadata.json** 是注册表文件，决定 Skill 能否被 discovery 与触发。
3. **references/** 是知识库，为 Skill 提供经典依据与深度背景。
4. **sources/** 是原始材料存放处（可选）。
5. **index/** 是速查文件，供快速查阅。

## 学派说明

**兵家** 是中国古代战略家学派，以《孙子兵法》为核心，重「全胜」「先胜后战」「避实击虚」「因敌变化」「以迂为直」。不是教人好战，而是以最小代价获取最大优势的系统��衡。用于竞争策略、资源配置、时机把握、攻守转换、风险评估。
