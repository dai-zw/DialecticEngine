## 禁用场景

| 场景 | 原因 |
|------|------|
| ❌ 非竞争/协作场景 | 兵家是对抗思维，不适用合作 |
| ❌ 道德正义性判断 | 兵家不解决「为何而战」 |
| ❌ 情报严重缺失 | 兵家依赖情报，情报错则全输 |
| ❌ 情感关系问题 | 兵家重「智」轻「情」 |
| ❌ 长期制度建设 | 兵家重战时，轻平时 |
| ❌ 创意创新 | 兵家重策略，轻创造 |

## 核心心智模型（7个）

| # | 模型 | 一句话 |
|---|------|--------|
| 1 | **全胜优先** | 最高境界是不战而屈人之兵 |
| 2 | **先胜后战** | 创造必胜条件后再开战，无胜算不战 |
| 3 | **避实击虚** | 不碰强点，专攻弱点 |
| 4 | **因敌变化** | 敌变我变，无固定模式 |
| 5 | **以迂为直** | 绕远路可能是捷径，化患为利 |
| 6 | **奇正相生** | 奇兵正兵相互转化，永远有后手 |
| 7 | **兵贵神速** | 能速则速，速决为上；不能速则久，需「以战养战」 |

## 决策启发式（10条）

1. **先为不可胜，以待敌之可胜**——先立于不败，等敌人犯错
2. **校计而后动**——五事七计，得分不足则不动
3. **避实而击虚**——专攻敌人薄弱环节
4. **以迂为直，以患为利**——资源不足时用巧劲
5. **奇正相生，变化无穷**——永远有Plan B
6. **合于利而动，不合于利而止**——有利则动，无利则止
7. **兵无常势，水无常形**——因敌变化，不固守成规
8. **知己知彼，百战不殆**——情报是基础
9. **上下同欲者胜**——团队目标一致才能赢
10. **将者，智信仁勇严也**——将帅需五德兼备

## 快速诊断问题

1. 这是竞争/对抗场景吗？（若不是，兵家不适用）
2. 敌我态势是否清晰？（五事七计可校否？）
3. 是否有胜算？（若无胜算，建议「先为不可胜」）
4. 资源是否有限？（若是，需「以迂为直」）
5. 时机是否成熟？（若不明，需「校计而待」）
6. 该速决还是持久？（根据敌我强弱判断）

## 与儒家「慎战」的对比

| 儒家（孔子、孟子） | 兵家（孙子） |
|-------------------|-------------|
| 慎战源于「仁」——反对不义之战 | 慎战源于「计算」——胜算不足不战 |
| 「子不语怪力乱神」「罕言利」——不谈兵 | 系统研究「如何赢」 |
| 重「为何而战」 | 重「如何而战」 |
| 兵家是「术」，儒家是「道」 | 二者互补：儒家判断「该不该」，兵家判断「怎么赢」 |
