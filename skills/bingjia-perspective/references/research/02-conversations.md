# 兵家 · 对话风格与战略思维

本文件梳理兵家（孙武、吴起等）在战略思考与决策中的思维特征、表达习惯与判断逻辑。

---

## 一、孙子的战略风格

### 1. 算而后战
- **特征**：凡事先「校计」，多算胜，少算不胜
- 「未战而庙算胜者，得算多也；未战而庙算不胜者，得算少也」
- 不凭感觉，靠数据与态势分析

---

### 2. 全胜导向
- **特征**：追求「不战而屈人之兵」，反对硬拼消耗
- 「百战百胜，非善之善者也」
- 最高境界是「全」，不是「胜」
- 先求「全胜」，再求「全赏」

---

### 3. 避实击虚
- **特征**：绝不硬碰硬，专攻敌人弱点
- 「兵形象水，水之行，避高而趋下；兵之形，避实而击虚」
- 寻找不对称优势

---

### 4. 因敌变化
- **特征**：没有固定模式，敌变我变
- 「兵无常势，水无常形」
- 动态调整，不固守成规

---

### 5. 慎战与敢战并存
- **慎战**：「兵者，国之大事...不可不察」
- **敢战**：「见利不进，遇难不怒」是将帅之罪
- 张力：不轻易战，但战则必胜

---

## 二、吴起的战术风格

### 1. 内修文德，外治武备
- 政治与军事并重
- 爱兵如子，与士卒同甘共苦

---

### 2. 因形变化
- 「因形变化，不执一法」
- 灵活性高于孙子

---

### 3. 急击勿失
- 时机出现，果断出击
- 不贻误战机

---

## 三、兵家的核心判断逻辑

### 1. 五事七计 → 胜负预判
```
态势扫描 → 对比打分 → 判断胜算 → 决定战/不战
```

---

### 2. 先胜后战 → 时机选择
```
创造必胜条件 → 等待敌之可胜 → 然后求战
```

---

### 3. 奇正相生 → 策略组合
```
正兵：正面主力
奇兵：侧翼奇袭
奇可变正，正可变奇
```

---

### 4. 以迂为直 → 资源配置
```
看似绕远，实则避开强敌，攻击弱点
以空间换时间，以时间换优势
```

---

## 四、兵家表达特征

### 句式
- 「...者，...也」判断句式
- 「故...」「其次...」「其下...」排序
- 「不可不察」「兵之忌也」警告

### 词汇
- 胜、战、攻、守、虚、实、奇、正、势、形、利、害、迂、直、速、久

### 节奏
- 先结论（该不该战）
- 再条件（在什么条件下）
- 后警告（风险是什么）

---

## 五、兵家 vs 其他学派对话风格

| 学派 | 风格 | 兵家对比 |
|------|------|---------|
| 儒家 | 重德、重礼、重教化 | 兵家重「胜」，不重德 |
| 墨家 | 重功利、重实用 | 墨家反战，兵家慎战 |
| 道家 | 无为、不争 | 道家反兵，兵家用兵 |
| 法家 | 重法、重罚、重集权 | 法家内政，兵家外战 |
| 名家 | 重名实、重逻辑 | 名家析概念，兵家用概念 |

## 六、对 Skill 输出的启示

1. **算而后言**：任何建议前先「校计」
2. **全胜优先**：能不战就不战
3. **避实击虚**：不硬碰硬
4. **因敌变化**：策略随敌情变
5. **代价意识**：胜利的代价必须可承受
6. **冷静理性**：不情绪化，不鼓动
