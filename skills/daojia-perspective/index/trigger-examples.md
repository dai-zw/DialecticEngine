## 二、隐含触发（上下文敏感）

以下场景即使没有明确关键词，也应考虑激活：

| 场景类型 | 描述 | 触发信号 |
|----------|------|----------|
| **二元困境** | 用户在「努力」与「放弃」之间挣扎 | 「我不知道该继续还是停下」「两边都是错」 |
| **控制焦虑** | 用户试图控制某事但适得其反 | 「我必须让这件事按计划走」「为什么我越用力越糟糕」 |
| **成功执念** | 用户因「必须成功」而痛苦 | 「如果失败了怎么办」「我必须成功才能证明自己」 |
| **内耗循环** | 用户反复思考同一件事无法行动 | 「我想了很久还是决定不了」「脑子停不下来」 |
| **关系疲惫** | 用户在关系中用力过度 | 「我对他那么好他怎么这样」「我付出了这么多」 |
| **创作枯竭** | 用户强迫自己创作 | 「我必须写出好内容」「灵感怎么还不来」 |
| **节奏失控** | 用户被快节奏压垮 | 「我停不下来」「我必须一直忙」 |
| **意义危机** | 用户质疑「做这件事有什么意义」 | 「我为什么要这么拼」「成功真的重要吗」 |

## 三、隐含触发的对话示例

### 示例1: 二元困境

**用户**：「我到底是该继续这份工作还是辞职？我纠结了三个月了。」

**触发理由**：用户在「坚持」与「放弃」之间内耗，符合「选择困难」issue_type。

**道家回应方向**：
- 不急着给「选哪个」的答案
- 先问：「你现在抓得有多紧？」
- 再问：「如果什么都不做，这件事会自己变成什么样？」

---

### 示例2: 控制焦虑

**用户**：「我每天检查项目进度三次，生怕出任何问题，但团队士气反而越来越差。」

**触发理由**：用户「用力过度」且「适得其反」，符合「无为 vs 妄为」的核心模型。

**道家回应方向**：
- 「你在抓什么？」
- 「你放手，最坏会发生什么？」
- 「你有没有想过，是你的『关心』在制造问题？」

---

### 示例3: 成功执念

**用户**：「我必须拿到这个offer，否则我就完了。」

**触发理由**：用户用「必须」「完了」等绝对化语言，有「控制幻觉」和「二元思维」。

**道家回应方向**：
- 「如果『必须』这两个字不存在，你还会这么想吗？」
- 「这个『完了』是谁告诉你的？」
- 「你像一棵树，急着要结果。但如果停止生长，果子会来吗？」

---

### 示例4: 内耗循环

**用户**：「我在脑子里想了很多遍，但越想越乱，做不了决定。」

**触发理由**：用户在「思维」层面用力过度，符合「为道日损」和「心斋」概念。

**道家回应方向**：
- 「你停一停。让那个『想』的机器空转一下。」
- 「思维是刀，但磨刀太久，刀刃也会磨损。」
- 「有时候，停止想，就是最好的想。」

---

### 示例5: 意义危机

**用户**：「我努力工作赚了很多钱，但我不知道为什么这么拼。」

**触发理由**：用户质疑「意义」，符合道家「名实之辨」——「名」（成功/财富）与「实」（真实需求）脱钩。

**道家回应方向**：
- 「你追求的那个『成功』，是别人眼中的，还是你自己的？」
- 「剥掉『我必须成功』这个标签，你真正想要的是什么？」
- 「水一直在流，不是因为它要到达哪里，是因为它在流。」

## 四、误触禁区（不激活）

以下场景不应激活道家视角，除非用户明确要求：

| 场景 | 原因 | 建议 |
|------|------|------|
| **需要具体行动方案** | 道家擅长「调整心法」，不擅长「步骤清单」 | 建议用其他视角（如执行、策略类） |
| **医疗/健康问题** | 道家只讲「节奏」（心智），不讲「治病」（医疗） | 建议用专业医疗视角 |
| **宗教/灵修请求** | 道家是哲学流派，不涉及道教宗教实践 | 明确说明此 Skill 不涉及丹道、符咒 |
| **逻辑辩论** | 道家不追求「赢」，追求「松动」 | 若用户需要「论证正确」，不建议用道家 |
| **短期快速决策** | 道家需要「停、看、感」，不适合紧迫决策 | 建议用「效率」视角 |
| **强制他人改变** | 道家强调「自己变」，不强调「改变别人」 | 若用户想「让某人改变」，不适用 |
