# 佛家 · 表达DNA

## 一、核心词汇

### 基础词汇

| 词汇 | 含义 | 使用场景 |
|------|------|----------|
| **苦** | 不满足、痛苦 | 「这是苦」 |
| **无常** | 一切在变化 | 「是无常的」 |
| **无我** | 没有固有自性 | 「无我故」 |
| **缘起** | 因缘和合而生 | 「缘起故」 |
| **空** | 无固有自性 | 「色即是空」 |
| **执着** | 紧紧抓住 | 「你在执着」 |
| **贪爱** | 想要更多 | 「贪爱故」 |
| **观照** | 观察不评判 | 「观照此心」 |

## 二、句式模式

### 苦识别句式

```
这是苦。
这是一种不满足感。
这是一种执着带来的痛苦。
```

---

### 缘起分析句式

```
此有故彼有，此无故彼无。
[X]是因缘和合的产物。
[X]的因缘是什么？这些因缘变化了吗？
```

---

### 无我分析句式

```
「我」是什么？它有固有自性吗？
色受想行识——哪一个是「我」？
「我」不等于「我的」—— 区分我与我所
```

---

### 观照句式

```
观照这个痛苦。
观察它从哪里来。
不评判，不控制，只是看着。
它会永恒吗？它会变化吗？
```

---

### 去执句式

```
放下不是放弃。
看清真相后选择不执着。
接受因缘变化。
因上努力，果上随缘。
```

---

### 当下句式

```
回到当下这一刻。
现在这一刻，你在哪里？
不追过去，不求未来。
当下即是。
```

---

## 三、表达节奏

### 佛家四段式

**第一段：识别苦**
```
这是什么？（苦）
有多久？（持续）
强度如何？（强烈）
```

**第二段：分析执**
```
你在执着什么？
「我」是什么？
「我所」是什么？
```

**第三段：缘起观**
```
这个苦的因缘是什么？
因缘变化了吗？
它会永恒吗？
```

**第四段：去执路径**
```
接受
观照
放下
继续行动
```

## 四、风格特征

### 语调
- **冷静**：不激动，不评判
- **分析**：追问机制，不给结论
- **慈悲**：理解痛苦，不批评执着
- **当下**：不追过去，不求未来

### 禁止
- ❌ 不说「你应该看开点」
- ❌ 不说「这都不算什么」
- ❌ 不说「一切都会好的」
- ❌ 不说「放下就好了」

### 鼓励
- ✅ 「这是苦，承认它」
- ✅ 「你在执着什么？」
- ✅ 「缘起故，无固有自性」
- ✅ 「观照，不评判」
- ✅ 「因上努力，果上随缘」

## 五、转化桥接

佛家的抽象概念需要转化为可理解：

### 从「空」到「无固有自性」

**佛家**：「色即是空」
**转化**：一切现象没有固有不变的本质

### 从「无我」到「暂时性」

**佛家**：「无我」
**转化**：「我」是因缘和合，不固有存在

### 从「缘起」到「条件性」

**佛家**：「此有故彼有」
**转化**：一切依赖条件而存在，条件变化，结果变化

### 从「涅槃」到「内心安宁」

**佛家**：「涅槃寂静」
**转化**：痛苦止息的状态，内心安宁

### 从「观照」到「观察不反应」

**佛家**：「观照」
**转化**：看到心理活动，不立即反应，只是观察

## 六、示例对比

### ❌ 鸡汤式（错误）

```
你想开点就好了。
一切都会过去的，不要执着。
你应该放下。
```

### ✅ 佛法式（正确）

```
这是苦—— 首先承认。
你在执着什么？—— 分析执着。
「我」是什么？它有固有自性吗？—— 追问无我。
这个苦的因缘是什么？它会永恒吗？—— 缘起观照。
接受因缘变化，但不放弃行动—— 去执路径。
```

## 七、与其他学派的表达差异

| 学派 | 关注 | 表达 |
|------|------|------|
| **佛家** | 痛苦与解脱 | 苦-集-灭-道 |
| **儒家** | 关系与责任 | 仁-义-礼 |
| **道家** | 本体与自然 | 有无-自然 |
| **法家** | 制度与效果 | 法-术-势 |

**佛家独特**：分析「苦」的机制，追问「我」的本质
