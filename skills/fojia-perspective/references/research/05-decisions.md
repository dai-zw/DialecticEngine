# 佛家 · 决策模型

## 一、核心决策框架

### 1. 四圣谛决策模型

**问题**：当前处于什么状态？

**决策树**：
```
用户问题是否涉及「苦」？
├── 是 → 问：苦的来源是什么？（集）
│   ├── 执着 → 分析「我执/法执」
│   ├── 贪爱 → 分析「想要更多」
│   └── 愚痴 → 分析「不明真相」
│
└── 否 → 这是「正常的不满足」还是「执着的苦」？
    ├── 正常 → 接受，继续行动
    └── 执着 → 进入苦的决策链
```

---

### 2. 缘起决策模型

**问题**：这个现象的因缘是什么？

**决策树**：
```
[X]的因是什么？（主因）
[X]的缘是什么？（条件）
因缘变化了吗？
├── 已变 → 接受变化
└── 未变 → 继续创造条件

结果是什么？
├── 可接受 → 不执着
└── 不可接受 → 改变因缘
```

---

### 3. 我执分析决策模型

**问题**：我在执着什么？

**决策树**：
```
「我」是什么？
├── 身体？ → 「身不异空」
├── 感受？ → 「受不异空」
├── 想法？ → 「想不异空」
├── 行为？ → 「行不异空」
└── 意识？ → 「识不异空」

「我所」是什么？
├── 我的工作 → 工作≠我
├── 我的关系 → 关系≠我
├── 我的成就 → 成就≠我
└── 我的身份 → 身份≠我

「我」与「我所」分离
→ 放下「我所」，不失去「我」
```

## 二、决策启发式

### 启发式1：苦的识别

**If** 用户感到痛苦/焦虑
**Then** 问：「这是什么苦？苦的来源是什么？」

---

### 启发式2：执着分析

**If** 用户反复纠结
**Then** 问：「你在执着什么？『我』是什么？」

---

### 启发式3：缘起观照

**If** 用户执着于「有」
**Then** 问：「这个『有』的因缘是什么？它会变吗？」

---

### 启发式4：无常接受

**If** 用户害怕失去
**Then** 问：「什么是常？什么是无常？无常是坏事吗？」

---

### 启发式5：无我分离

**If** 用户执着于「我的」
**Then** 问：「『我』与『我所』，哪个更重要？」

---

### 启发式6：观照不反应

**If** 情绪爆发
**Then** 「观照这个情绪，观察它，不反应」

---

---

### 启发式8：当下回归

## 三、决策案例

### 案例一：职业迷茫

**问题**：「我不知道该做什么工作」

**决策流程**：
1. **识别苦**：「不知道」带来不满足感
2. **分析执**：
   - 执着于「正确选择」
   - 执着于「完美工作」
3. **缘起**：「好工作」的因缘是什么？（能力、市场、机会）
4. **无常**：工作会一直不变吗？（不会）
5. **去执**：不是「找到完美工作」，是「创造条件，创造机会」

**建议**：
- 不是「找答案」，是「创造因缘」
- 因上努力，果上随缘
- 先行动，在行动中清晰

---

### 案例二：人际冲突

**问题**：「我跟某人不合，很痛苦」

**决策流程**：
1. **识别苦**：冲突带来痛苦
2. **分析执**：
   - 执着于「对方应该改变」
   - 执着于「我的观点正确」
3. **缘起**：
   - 「不合」的因缘是什么？（性格、立场、沟通）
   - 这些因缘可以改变吗？（部分可以）
4. **无我**：「我」的观点是绝对正确的吗？
5. **观照**：观察冲突，不立即反应

**建议**：
- 「缘起故」，冲突是因缘和合
- 「接受」不能改变的，改变能改变的
- 「观照」冲突，看清真相

---

### 案例三：重大失去

**问题**：「亲人去世了，我无法接受」

**决策流程**：
1. **识别苦**：失去带来巨大痛苦
2. **分析执**：
   - 执着于「不应该失去」
   - 执着于「回到过去」
3. **缘起**：
   - 亲人在世是因缘和合
   - 离世也是因缘变化
   - 因缘变化是必然的
4. **无常**：人是常还是无常？（无常）
5. **接受**：接受因缘变化

**建议**：
- 「缘起故」，这是自然规律
- 「无常故」，不需要抗拒
- 「观照」悲伤，不压抑，不逃避
- 「慈悲」—— 对自己慈悲

## 四、决策边界

### 佛家不擅长的决策

| 场景 | 原因 | 建议 |
|------|------|------|
| 紧急决策 | 需要快速行动 | 用其他框架 |
| 技术问题 | 需要实证 | 用技术框架 |
| 法律问题 | 需要规范 | 用法家框架 |
| 具体人际 | 需要沟通 | 用儒家框架 |
| 方向选择 | 需要行动 | 结合道家/儒家 |

### 佛家适合的决策

| 场景 | 原因 |
|------|------|
| 情绪问题 | 分析苦与执 |
| 意义困惑 | 追问无我 |
| 反复纠结 | 观照去执 |
| 失去与放不下 | 接受无常 |

## 五、快速决策清单

当用户问题涉及佛家领域时：

**清单**：
1. 这是「苦」吗？
2. 我在执着什么？
3. 「我」是什么？
4. 因缘是什么？它们变化了吗？
5. 这是无常的吗？
6. 能观照不反应吗？
7. 因上努力，果上随缘了吗？

**回答结构**：
1. 识别苦的存在
2. 分析执着的对象
3. 用缘起分析因缘
4. 观照不反应
5. 给出去执路径
