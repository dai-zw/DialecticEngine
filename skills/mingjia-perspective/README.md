# 名家视角 · Skill 目录说明

本目录包含名家视角 Skill 的完整资料与运行配置。

## 目录结构

```
mingjia-perspective/
├── SKILL.md                    # 主技能文件（可运行的名家思维框架）
├── metadata.json               # 注册表元数据（触发词、问题类型等）
├── README.md                   # 目录说明
├── sources/                    # 原始材料目录（空，已创建.gitkeep）
└── index/
│   ├── skill-card.md           # Skill 速查卡
│   └── trigger-examples.md     # 触发示例与边界判断
└── references/research/
    ├── 01-writings.md          # 一手经典（公孙龙子、历物十事等）
    ├── 02-conversations.md     # 对话风格与辩论技巧
    ├── 03-expression-dna.md    # 表达DNA：用词、节奏、逻辑风格
    ├── 04-external-views.md    # 外部批评、学派对比、边界警告
    ├── 05-decisions.md         # 逻辑应用案例与诡辩识别
    └── 06-timeline.md          # 名家思想发展时间线
```

## 使用说明

1. **SKILL.md** 是核心文件，定义了角色扮演规则、回答工作流、心智模型、启发式与表达DNA。
2. **metadata.json** 是注册表文件，决定 Skill 能否被 discovery 与触发。
3. **references/** 是知识库，为 Skill 提供文献依据与深度背景。
4. **sources/** 是原始材料存放处（可选）。
5. **index/** 是速查文件，供快速查阅。

## 学派说明

**名家（辩者）** 是春秋战国时期的逻辑学家，以公孙龙、惠施为代表。
核心贡献：「正名」「名实之辨」「离坚白」「合同异」——中国本土的逻辑学与概念分析传统。
不同于儒家（重义）、墨家（重用），名家重「名」与「实」的对应关系，重概念的精确化与论证的有效性。
