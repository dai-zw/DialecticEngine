# 儒家视角 · Skill 目录说明

本目录包含儒家视角 Skill 的完整资料与运行配置。

## 目录结构

```
rujia-perspective/
├── SKILL.md                    # 主技能文件（可运行的思维框架）
├── metadata.json               # 注册表元数据（触发词、问题类型等）
├── references/                 # 参考文献库
│   └── research/
│       ├── 01-writings.md      # 一手经典文献（论语、孟子、礼记、荀子等）
│       ├── 02-conversations.md # 对话风格与表达模式
│       ├── 03-expression-dna.md # 表达DNA：用词、节奏、价值排序
│       ├── 04-external-views.md # 外部批评、学派对比、边界警告
│       ├── 05-decisions.md     # 历史决策案例与情境应用
│       └── 06-timeline.md      # 儒家思想发展时间线
├── sources/                    # 一手/二手材料（空目录，用于存放原始资料）
└── index/                      # 快速索引
    ├── skill-card.md           # Skill 速查卡
    └── trigger-examples.md     # 触发示例与边界判断
```

## 使用说明

1. **SKILL.md** 是核心文件，定义了角色扮演规则、回答工作流、心智模型、启发式与表达DNA。
2. **metadata.json** 是注册表文件，决定 Skill 能否被 discovery 与触发。
3. **references/** 是知识库，为 Skill 提供事实依据与深度背景。
4. **sources/** 是原始材料存放处（可选）。
5. **index/** 是速查文件，供快速查阅。

## 信息源说明

本 Skill 基于传世儒家经典（论语、孟子、礼记、荀子等）与现代学术研究（冯友兰、梁漱溟、牟宗三、杜维明等），综合先秦儒、汉儒、宋明理学、现代新儒家四大学派，标注内部差异与外部批评。
